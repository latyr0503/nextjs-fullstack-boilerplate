# Bienvenue sur votre Starter Kit

Ce projet a été conçu pour vous offrir un socle de démarrage complet, robuste et modulaire pour vos applications web modernes.

## Ce qui est inclus dans ce socle

1. **Next.js 16 (App Router)** : Architecture moderne basée sur les React Server Components.
2. **Tailwind CSS & Shadcn/UI** : Système de design pré-intégré avec plus de 40 composants accessibles (Radix UI) et gestion du Dark Mode.
3. **Gestion d'état avec Redux Toolkit** : Configuration centralisée du store et gestion de session auth.
4. **Client API avec RTK Query** : Gestion optimisée des requêtes, du cache automatique et de l'injection JWT (`store/baseApi.ts`).
5. **Base de données Neon PostgreSQL** : Connexion serverless prête pour vos tables et requêtes SQL (`@neondatabase/serverless`).
6. **API de contact & Notifications** : Route `/api/contact` connectée à Neon DB, envoi d'emails via Resend et alertes Telegram.
7. **Workflows n8n** : Dossier dédié pour vos automatisations, webhooks et agents IA (`/n8n`).
8. **Système de prompts IA** : Dossier `public/prompt/` pour versionner vos prompts système.
9. **Moteur de Blog Markdown** : Génération de pages et articles dynamiques à partir de fichiers Markdown avec métadonnées frontmatter.

Bon développement sur vos futurs projets !
